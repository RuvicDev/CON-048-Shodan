¿Qué es y para qué sirve?

El conector Shodan permite que el agente de Ruvic consulte el motor de búsqueda de dispositivos conectados a internet Shodan — investigar qué expone una IP, buscar dispositivos/servicios por término, y revisar qué puertos tiene abiertos un host.

Una vez configurado, puedes pedirle al agente cosas como:

  • "¿Qué servicios expone esta IP?"
  • "Busca servidores Apache expuestos en Alemania."
  • "¿Qué puertos tiene abiertos este host?"

Operaciones soportadas:

OperaciónQué hace
cybersecurity.get_host_infoConsulta toda la información indexada de una IP
cybersecurity.search_devicesBusca dispositivos/servicios expuestos por término
cybersecurity.get_open_portsObtiene solo los puertos abiertos de un host
Conector de solo lectura Shodan consulta un índice de dispositivos ya escaneados — este conector no ejecuta escaneos nuevos en tiempo real ni modifica nada.

Prerrequisitos

  • Una cuenta de Shodan (tiene un nivel gratuito con créditos limitados).
  • Saber aproximadamente cuántas búsquedas/consultas necesitará el agente, para elegir un plan con créditos suficientes si el uso va a ser frecuente.

Configuración en el fabricante

  1. Crea una cuenta en Shodan.

    Ve a account.shodan.io y regístrate.

  2. Copia tu API key.

    En la sección "API" de tu cuenta, vas a ver tu API key lista para copiar — no requiere ningún paso de aprobación adicional.

  3. Prueba desde línea de comandos (opcional pero recomendado). 
curl "https://api.shodan.io/api-info?key=TU_API_KEY"

Una respuesta con tus créditos y plan confirma que la API key funciona.

Permisos requeridos

No hay roles/permisos que configurar del lado de Shodan más allá de tener una API key válida — el alcance de lo que se puede consultar depende de los créditos de búsqueda/escaneo disponibles en tu plan.

Configuración en Ruvic

Entra a Settings → Conectores, busca la tarjeta Shodan y pulsa Configurar.

Pega tu API Key en el campo correspondiente. Deja "URL base de la API" en su valor por defecto.

Guarda y pulsa Probar conexión.

Verificación

  1. Test de conexión exitoso.

    El botón Probar conexión debe responder: "Conexión exitosa a https://api.shodan.io".

  2. Prueba mínima con el agente.

    Pide algo de bajo costo primero:

    "¿Qué puertos tiene abiertos la IP 8.8.8.8?"

Solución de problemas

Mensaje / síntomaCausa probable y solución
"API key inválida o revocada"Verifica que copiaste la key completa desde account.shodan.io → API.
"No encontrado" en get_host_info/get_open_portsShodan no tiene esa IP indexada — no significa necesariamente que el host esté caído, solo que Shodan no la ha escaneado o indexado.
"Límite de peticiones/créditos alcanzado"Se agotaron los créditos de búsqueda/consulta del plan — espera al siguiente ciclo o mejora el plan en Shodan.

Preguntas frecuentes y notas de seguridad

¿Este conector puede escanear una IP en tiempo real?

No. Consulta el índice ya recolectado por Shodan — no ejecuta un escaneo activo bajo demanda.

¿Los resultados son "vulnerabilidades confirmadas"?

No — Shodan reporta banners y servicios detectados. La interpretación de si eso representa un riesgo real la debe hacer una persona con contexto del sistema.

¿Dónde queda guardada la API key?

Como secreto en el almacén de credenciales de la plataforma. La interfaz nunca vuelve a mostrarla.

Buenas prácticas Ten presente que las búsquedas (search_devices) consumen créditos de tu cuenta — evita llamadas repetidas sin necesidad real; y no presentes los hallazgos como vulnerabilidades confirmadas sin revisión humana.
